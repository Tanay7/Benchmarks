# 05 - Telemetry & Command Dictionary

> GENERATED by `tools/gen_dictionary_doc.py` from `ground/dssq/dictionary.py` and the flight source. Do not edit by hand; re-run the script. The flight packers are verified against the same dictionary by `ground/tests/test_cross_check.py` (bit-exact).

Conventions: all fields big-endian (CCSDS network order). Engineering value = raw x scale. Sentinels mean *not available* and are shown as `None`/`-`: i16 0x7FFF, u16 0xFFFF, i32 0x7FFFFFFF, u32 0xFFFFFFFF, i8 -128; f32 NaN. Every TM packet carries a 6-octet CUC secondary header (SCLK, CCSDS 301.0-B-4, 4+2 octets) before the user data listed here.

## 1 Telemetry packets

APID 0x012 (EVR) and 0x015 (RFSCAN) are variable length:

* **EVR**: `severity u8 | event_id u16 | ASCII text (<= 80 chars)`
* **RFSCAN**: `first_ch u8 | count u8 | duration_ms u16 | noise_dbm i8 x count` (-128 = no reading)

## 4 Telecommands (uplinked; APID 0x0C0, user data = opcode + arguments)

Typed identically on the web console and on CardKB #1. Hazardous commands need CONFIRM (and 2nd-operator AUTH when the two-person rule is enabled). Prefix any command with `BD` to send it as a COP-1 bypass (Type-BD) frame.

| Mnemonic | Opcode | Arguments (name: type, range) | Hazardous | Description |
|---|---|---|---|---|
| `NOOP` | 0x01 | - |  | No operation (link check, advances counters) |
| `MODE` | 0x02 | mode: u8 1..4 (SAFE=1, CRUISE=2, ENCOUNTER=3, ENC=3, TEST=4) |  | Set flight-software mode: SAFE \| CRUISE \| ENCOUNTER \| TEST |
| `TXPWR` | 0x03 | code: u8 0..3 |  | Set E22 TX power code (NO effect on the E22-400T37S: every code is 37 dBm) |
| `AIRRATE` | 0x04 | code: u8 0..7, revert_s: u16 60..3600 | YES | Change air data rate (T37S: 0-2 = 2.4k, 3 = 4.8k, 4 = 9.6k ... 7 = 62.5k); spacecraft reverts after revert_s unless a TC is received |
| `FPERIOD` | 0x05 | ms: u16 500..60000 |  | Requested frame period (flight enforces the duty-cycle limit) |
| `PKTRATE` | 0x06 | apid: u16 16..35, period_s: u16 0..3600 |  | Set generation period of a telemetry packet (0 = off) |
| `PLAYBACK` | 0x07 | start: u8 0..1 (START=1, STOP=0) |  | Start/stop solid-state-recorder playback on VC2 |
| `SSRCLEAR` | 0x08 | - | YES | Erase the solid-state recorder |
| `PING` | 0x09 | tag: u32 0..4294967295 |  | Echo tag in CMDVER (round-trip time measurement) |
| `SENSORS` | 0x0A | mask: u16 0..65535 |  | Instrument enable mask (b0 Nicla ME, b7 Nicla Env, b11 AS7265X, b12/b13 RM3100) |
| `RSTCNT` | 0x0B | - |  | Reset HK/RF counters |
| `REBOOT` | 0x0C | magic: u16 45063..45063 | YES | Reboot the flight computer (magic 0xB007) |
| `MAGCC` | 0x0D | cycle_count: u16 50..400 |  | RM3100 cycle count (sensitivity/noise vs. rate) |
| `CMDLOSS` | 0x0E | seconds: u32 0..604800 | YES | Command-loss timer (0 disables) - enters SAFE on expiry |
| `FDIRMASK` | 0x0F | mask: u16 0..65535 | YES | FDIR response enable mask |
| `TXINHIBIT` | 0x10 | seconds: u16 10..3600 | YES | Silence the transmitter for N seconds (auto re-enable) |
| `EVRLEVEL` | 0x11 | level: u8 0..4 |  | Minimum EVR severity downlinked |
| `TIMECORR` | 0x12 | - |  | Generate a TIMECORR packet now |
| `RFSCAN` | 0x13 | first_ch: u8 0..83, last_ch: u8 0..83 |  | Spacecraft RF survey: ambient noise on each E22 channel (downlink paused) |
| `HIBERNATE` | 0x14 | beacon_s: u16 60..3600 | YES | Wake-on-Radio hibernation, one HK beacon every beacon_s (wake with WAKE) |
| `CHANNEL` | 0x15 | ch: u8 0..83, revert_s: u16 60..3600 | YES | Change RF channel; reverts after revert_s unless a TC arrives on the new channel |
| `SPECCFG` | 0x16 | gain: u8 0..3, cycles: u8 1..255, lamps: u8 0..7 |  | AS7265X gain (0 1x,1 3.7x,2 16x,3 64x), integration cycles x 2.8 ms, lamps b0 white b1 IR b2 UV (lit only while measuring) |
